# how to add a news post

easy. drop a markdown file into this folder named like:

    2026-09-22-my-cool-update.md

rules:

- the filename must start with a date in the form YYYY-MM-DD.
- the first line must be the title, starting with `# `.
- everything after that is the body. write markdown freely.
- posts are shown newest first. files starting with `_` or missing the date prefix are ignored.
